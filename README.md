## 它能做什么

- 说 **"帮我发布一篇介绍网站的文章"** → 自动创建分类、撰写并发布
- 说 **"给站点装个缓存插件"** → 自动搜索、安装、启用
- 说 **"给主题加特色图片功能"** → 自动读写 functions.php（改动前自动备份）
- 说 **"优化数据库"** → 自动备份 + 清理缓存
- 说 **"每天备份数据库"** → 创建定时任务，到点自动执行
- 说 **"让生图助手配合发一篇图文"** → 多角色协作，生图 + 发文一条龙

## 安装

1. 下载最新版 zip（[Releases](https://github.com/wpomniagentAI/tianma-chat/releases)）
2. 后台 **插件 → 安装插件 → 上传插件**，选择 zip 上传安装并启用
3. 进入 **天马智能体 → 模型设置**，填入大模型 API Key
   - 推荐：**腾讯云混元**（新用户送 100 万 Tokens）｜**阿里云通义千问**（每款模型送 100 万 Tokens）
4. 回到 **天马智能体 → 对话**，直接开聊
