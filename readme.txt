== Description ==

「天马行空 WP 智能体」（简称天马）是一个真正意义上的 AI Agent 插件，而非简单的聊天机器人：

* 官网及更新：https://github.com/wpomniagentAI/tianma-chat ｜ 国内镜像（Gitee）：https://gitee.com/xxx5545/tianma-chat ｜ QQ：3908349048（欢迎加我一起讨论拓展）
* 本插件免费开源使用，任何利用插件收费的都是骗子；插件内置广告位是作者加的，有需要请支持下作者

= 核心能力 =

* 对话式管理：用自然语言下达指令，Agent 自主规划、调用工具、执行、汇报
* 全站操作：文章/页面/媒体发布管理、主题与插件安装管理、文件与代码编辑、系统设置与维护
* 自学习记忆：内置向量记忆库，任务经验自动沉淀（情景/语义/程序三种记忆），相似任务自动检索复用
* 高危确认：删除、覆盖、改库等危险操作执行前请求用户确认
* 完整审计：所有工具操作留痕，可追溯
* 多模型支持：OpenAI 兼容 API，内置 DeepSeek / 通义千问 / OpenAI 预设，可自由切换

= 工具清单（40 项） =

内容：站点信息 / 文章增删改查 / 页面增删改查 / 媒体列表与上传 / 分类管理
文件：目录列表 / 读取 / 写入（自动备份）/ 删除 / 重命名 / 建目录 / PHP 语法检查
主题插件：插件列表 / 启用 / 停用 / 删除 / 安装 / 主题列表 / 切换 / 删除 / 创建插件骨架 / 创建主题骨架
系统：站点设置查看与修改 / 用户列表与创建 / 数据库备份 / 缓存清理 / 更新检查 / 日志查看 / 只读 SQL 查询

= 自学习机制 =

* 情景记忆：每次任务的完整执行记录
* 语义记忆：提炼的任务知识与经验（向量化存储，语义检索）
* 程序记忆：成功任务的工具序列固化为技能
* 用户反馈：点赞/踩影响经验权重，越用越懂你

== Installation ==

1. 上传插件目录 tianma 到 /wp-content/plugins/ 并启用
2. 进入「天马智能体 → 模型设置」，选择服务商并填写 API Key
3. 没有 Key 可先启用「本地演示模式」体验完整流程
4. 保存后进入「天马智能体 → 对话」开始使用

== Frequently Asked Questions ==

= 需要付费吗？ =
插件免费。你需要自备大模型 API Key（DeepSeek、通义千问等）。

= 数据安全吗？ =
所有请求直接发送到你配置的模型服务商；工具操作均记录审计日志；高危操作需你确认。
